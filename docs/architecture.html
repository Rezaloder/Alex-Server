معماری Alex Server

سه روش اتصال برای کاربران. همهٔ ترافیک فقط از یک تونل WireGuard به یک خروجی خارج از کشور می‌رود. اگر تونل قطع شود، کاربران اینترنت ندارند و هیچ ترافیکی از IP خود سرور بیرون نمی‌رود.

نقشهٔ اتصال‌ها

هر کاربر چطور به اینترنت می‌رسد

VLESS + Reality

اپ به SHARE_ADDR:443 وصل می‌شود. از بیرون، اتصال شبیه HTTPS به سایت هدف (مثلاً دیجی‌کالا) دیده می‌شود. Xray کاربر را با UUID شناسایی می‌کند و مصرفش را ثبت می‌کند. خروجی egress بسته‌ها را با mark 0x200 علامت می‌زند. بعد جدول 200، تونل wg-out و خروجی.

L2TP/IPsec

اتصال با IKEv1 و PSK روی UDP 500 و 4500 برقرار می‌شود. داخل IPsec یک نشست L2TP و PPP ساخته می‌شود و کاربر IP 10.203.62.x می‌گیرد. قاعدهٔ from 10.203.62.0/24 → table 200 ترافیک را به wg-out می‌فرستد، با masquerade فقط روی همین تونل.

WireGuard

کلاینت به UDP 51820 وصل می‌شود و IP 10.203.61.x می‌گیرد. مسیرش مثل L2TP است. کاربران با wg-user ساخته می‌شوند و QR می‌گیرند.
